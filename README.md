# Real-World ETL Data Pipeline

##  Project Overview

This project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline using a real-world Superstore sales dataset.

The pipeline extracts raw data, validates data quality, transforms and standardizes the dataset, loads the processed data into a SQLite database, and performs business analysis using SQL.

---

##  Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Google Colab

---

##  ETL Workflow

```text
Raw Superstore Dataset
        ↓
Extract Data
        ↓
Data Inspection & Validation
        ↓
Data Transformation
        ↓
Load into SQLite
        ↓
SQL Business Analysis
        ↓
Data Quality Reporting
        ↓
Export Processed Dataset
